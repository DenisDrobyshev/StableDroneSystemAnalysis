## 1. Обзор системы

### 1.1. Назначение системы
Система анализа устойчивости динамических систем БПЛА предназначена для:
- Моделирования динамики беспилотных летательных аппаратов
- Анализа устойчивости систем управления
- Визуализации переходных процессов
- Сравнения различных стратегий управления

### 1.2. Основные возможности
- **Моделирование динамики**: Интеграция уравнений движения методом Эйлера и Рунге-Кутты 4-го порядка
- **Анализ устойчивости**: Расчет собственных чисел, определение типа устойчивости
- **Визуализация**: Построение графиков положения, скорости, управления и фазовых портретов
- **Сравнительный анализ**: Одновременное сравнение multiple управляющих воздействий
- **Интерактивный интерфейс**: Современный GUI с возможностью изменения параметров в реальном времени

### 1.3. Технический стек
- **Язык программирования**: Python 3.8+
- **Графический интерфейс**: Tkinter
- **Математические вычисления**: NumPy, SciPy
- **Визуализация**: Matplotlib
- **Архитектура**: Объектно-ориентированное программирование

## 3. Математическая модель

### 3.1. Основные уравнения
Система описывается моделью "масса-пружина-демпфер":

```
m·ẍ + c·ẋ + k·x = u(t)
```

где:
- `m` - масса системы [кг]
- `c` - коэффициент демпфирования [Н·с/м]
- `k` - коэффициент жесткости [Н/м]
- `u(t)` - управляющее воздействие [Н]
- `x` - положение системы [м]

### 3.2. Приведение к системе первого порядка
```
da₁/dt = a₂
da₂/dt = (u(t) - c·a₂ - k·a₁) / m
```

где:
- `a₁ = x` - положение
- `a₂ = dx/dt` - скорость

### 3.3. Методы интегрирования

#### 3.3.1. Метод Эйлера
```python
a₁[i+1] = a₁[i] + dt · a₂[i]
a₂[i+1] = a₂[i] + dt · (u(t) - c·a₂[i] - k·a₁[i]) / m
```

#### 3.3.2. Метод Рунге-Кутты 4-го порядка
```python
k1_a1 = a₂[i]
k1_a2 = (u(t) - c·a₂[i] - k·a₁[i]) / m

k2_a1 = a₂[i] + 0.5·dt·k1_a2
k2_a2 = (u(t+0.5·dt) - c·(a₂[i]+0.5·dt·k1_a2) - k·(a₁[i]+0.5·dt·k1_a1)) / m

# ... аналогично для k3, k4

a₁[i+1] = a₁[i] + (dt/6)·(k1_a1 + 2·k2_a1 + 2·k3_a1 + k4_a1)
a₂[i+1] = a₂[i] + (dt/6)·(k1_a2 + 2·k2_a2 + 2·k3_a2 + k4_a2)
```

### 3.4. Анализ устойчивости

#### 3.4.1. Характеристическое уравнение
```
λ² + (c/m)·λ + (k/m) = 0
```

#### 3.4.2. Собственные числа
```
λ₁,₂ = [-c/m ± √((c/m)² - 4·k/m)] / 2
```

#### 3.4.3. Критерии устойчивости
- **Устойчивая система**: Re(λ₁) < 0 и Re(λ₂) < 0
- **Критическое демпфирование**: (c/m)² = 4·k/m
- **Колебательная система**: (c/m)² < 4·k/m

## 6. Руководство пользователя

### 6.1. Запуск приложения
1. Запустите `main.py`
2. Дождитесь загрузки графического интерфейса
3. Система автоматически выполнит первоначальное моделирование

### 6.2. Основные элементы интерфейса

#### 6.2.1. Панель управления
- **Тип управления**: Выбор управляющего воздействия
- **Метод интегрирования**: Эйлер или Рунге-Кутта 4
- **Параметры системы**: Масса, демпфирование, жесткость
- **Кнопки управления**: Запуск, сравнение, анализ

#### 6.2.2. Область графиков
- **График 1**: Положение системы a₁(t)
- **График 2**: Скорость системы a₂(t)
- **График 3**: Управляющее воздействие u(t)
- **График 4**: Фазовый портрет a₂(a₁)

#### 6.2.3. Информационная панель
- Статус системы
- Результаты анализа устойчивости
- Параметры моделирования

### 6.3. Рабочие процедуры

#### 6.3.1. Базовое моделирование
1. Выберите тип управления из выпадающего списка
2. Нажмите "Запустить моделирование"
3. Наблюдайте результаты на графиках
4. Изучите информацию об устойчивости

#### 6.3.2. Сравнительный анализ
1. Нажмите "Сравнить все"
2. Система выполнит моделирование для всех типов управления
3. Сравните результаты на объединенных графиках

#### 6.3.3. Анализ устойчивости
1. Нажмите "Анализ устойчивости"
2. Изучите окно с детальной информацией:
   - Собственные числа системы
   - Тип устойчивости
   - Рекомендации по настройке

#### 6.3.4. Настройка параметров
1. Измените значения в полях параметров
2. Нажмите "Применить параметры"
3. Система пересчитает модель с новыми параметрами

### 6.4. Типы управляющих воздействий

| Тип управления | Формула | Описание |
|----------------|---------|----------|
| Без управления | u(t) = 0 | Свободные колебания |
| Плавное нарастание | u(t) = min(1.0, 0.2·t) | Плавное увеличение |
| Синусоидальное | u(t) = 0.5·sin(0.5·t) | Гармоническое воздействие |
| Постоянное | u(t) = 0.3 | Постоянная сила |
| Импульсное | Импульс в интервале t∈[10,20] | Кратковременное воздействие |
| Ступенчатое | u(t) = 0.4 при t>15 | Скачкообразное изменение |
| Стабилизирующее | u(t) = -0.1·t (t<10), 0.1 (t≥10) | Управление с обратной связью |
